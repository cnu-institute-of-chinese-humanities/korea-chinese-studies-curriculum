# 코드북 (Codebook)

한국 대학의 중국학 유관 학과 교과과정 데이터셋 — 변수 정의서

이 문서는 데이터의 모든 열이 무엇을 뜻하고 어떤 값을 가지는지 기술합니다.
**변수를 추가하거나 값 체계를 바꿀 때는 이 문서를 함께 갱신합니다.**

- 최종 갱신: 2026-09-03
- 대상 버전: v1.0.0
- 산출 스크립트: [`scripts/preprocess.py`](../scripts/preprocess.py)
- 수치의 근거: [`data/processed/_columns.json`](../data/processed/_columns.json) (스크립트가 자동 산출)

## 1. 데이터 개요

한국 소재 4년제 대학의 **중국학 유관 학과·전공·트랙과 그 교과과정**을 정리한 지식그래프 데이터셋입니다. 대학·캠퍼스·단과대학·학과 등의 **개체(노드)**와 그 사이의 **관계(엣지)**로 구성됩니다.

| 항목 | 값 |
|---|---|
| 수집 대상 | 78개 대학 |
| 교과과정 적용 연도 | 2025년 (단년도) |
| 개체 총계 | 4,894건 |
| 관계 총계 | 5,393건 |
| 인코딩 | UTF-8 (BOM 없음) |
| CSV 구분자 | 쉼표(`,`), 줄바꿈 LF |

### 커버리지

- **78개 대학 전부**에서 교과목이 수집되었습니다.
- 교과목을 개설하는 단위 94개(학과 58 + 전공 33 + 트랙 3) 중 **91개**에 교과목이 연결되어 있습니다.
- 개설 단위당 교과목 수는 최소 14개, 중앙값 43개, 최대 78개입니다.

### ⚠ 교과목이 붙는 단위가 대학마다 다릅니다

교과목은 대부분 **학과**에 붙어 있지만, 일부 대학은 교육과정을 **전공·트랙** 단위로 편성합니다. 교과목이 연결되지 않은 학과 3개는 누락이 아니라 이 경우입니다.

| 학과 | 교과목이 붙은 하위 단위 |
|---|---|
| 서강대_중국문화학과 (`Depa023`) | 문화학전공 57 · 지역학전공 56 |
| 한신대_중국어문화콘텐츠학 (`Depa054`) | 중국어문전공 54 · 한중콘텐츠전공 50 |
| 호서대_중국학과 (`Depa058`) | 중국사회문화트랙 42 · 중국비즈니스트랙 42 |

`edge`의 `Department --hasPart--> Major/Track` 관계 6건이 정확히 이 세 학과의 것입니다. 단과대학(80개)·학부(26개)에 교과목이 0개인 것도 같은 이유입니다(상위 조직).

> **개설 주체를 학과로만 세면 서강대·한신대·호서대가 0으로 잡힙니다.** 대학별로 집계할 때는 `hasPart` 관계를 따라 학과 → 전공·트랙까지 내려가거나, 교과목의 개설 단위를 대학 단위로 올려서 합산하십시오.

## 2. 파일 구성

같은 데이터를 세 가지 형태로 제공합니다. **내용은 동일하며 표현만 다릅니다.**

| 경로 | 용도 | 특징 |
|---|---|---|
| `data/raw/korea_chinese_studies_curriculum_2025.xlsx` | 원본 | 시트 11개. **수정하지 않음** |
| `data/processed/csv/*.csv` | 엑셀·SPSS·R | 다중값을 세미콜론(`;`)으로 연결 |
| `data/processed/json/*.json` | 프로그래밍 분석 | 다중값이 **배열**, 결측이 **null**, 숫자가 **숫자형** |
| `data/processed/graph.json` | 네트워크 분석 | `{nodes, edges}` 통합 구조 |
| `data/processed/campus.geojson` | 지도 시각화 | 캠퍼스 81개 지점 |
| `data/processed/_columns.json` | 기계 판독용 열 정의 | 이 문서의 근거 자료 |

`graph.json`은 Gephi·Cytoscape·networkx·D3에서 별도 가공 없이 읽힙니다.

```json
{"source": "Univ001", "target": "Camp001", "relationship": "hasPart",
 "sourceClass": "University", "targetClass": "Campus", "description": "대학과 캠퍼스의 관계"}
```

### 원본(xlsx)의 머리글

원본 시트의 머리글은 **두 줄**입니다. 첫 줄이 영문 변수명, 둘째 줄이 한글명입니다(예: `no` / `연번`). 전처리 산출물은 첫 줄(영문)을 열 이름으로 씁니다. `Edge` 시트만 영문 한 줄입니다.

`Class_Course` 시트의 V·W열은 원본에 머리글이 없습니다. 전처리에서 각각 `note`·`previousDescription`이라는 이름을 부여했습니다(4.6 참조).

## 3. 공통 규칙

### 3.1 모든 개체 파일에 있는 열

| 열 | 한글명 | 자료형 | 설명 |
|---|---|---|---|
| `no` | 연번 | 정수 | 파일 내 일련번호. **파일 간 비교에 쓰지 마십시오** |
| `class` | 클래스 | 문자열 | 개체 유형. 파일마다 단일값 |
| `id` | 식별자 | 문자열 | **전역 고유 식별자.** 관계 연결의 기준 |
| `name` | 대표명 | 문자열 | 표시용 이름. 조직은 `대학약칭_조직명` 형식 |

### 3.2 식별자 체계

`id`는 접두사 4자 + 일련번호 3~4자리입니다. **관계(`edge`)는 오직 `id`로만 연결되므로, `name`이 바뀌어도 분석에 영향이 없습니다.**

| 접두사 | 개체 | 예 | 건수 |
|---|---|---|---|
| `Univ` | 대학 | `Univ001` | 78 |
| `Camp` | 캠퍼스 | `Camp001` | 81 |
| `Coll` | 단과대학 | `Coll001` | 80 |
| `Facu` | 학부 | `Facu001` | 26 |
| `Depa` | 학과 | `Depa001` | 58 |
| `Majo` | 전공 | `Majo001` | 33 |
| `Trac` | 트랙 | `Trac001` | 3 |
| `EduG` | 교육목표 | `EduG001` | 88 |
| `Cour` | 교과목 | `Cour0001` | 4,012 |
| `Prof` | 교원 | `Prof001` | 435 |

**참조 무결성은 검증되었습니다.** 관계 5,393건이 가리키는 `id`가 모두 실재합니다.

### 3.3 결측 표기

- **JSON**: `null`
- **CSV**: 빈 칸
- 음수 코드(`-99` 등)는 **사용하지 않습니다**

다음은 결측이 아니라 **원본의 표기 그대로**입니다.

| 값 | 나오는 열 | 뜻 |
|---|---|---|
| `-` | `grade` 1건, `credit` 3건 | 대학이 해당 항목을 `-`로 공시한 것 |
| `계절` | `grade` 4건, `semester` 14건 | 계절학기 개설 과목 |
| `P` | `credit` 10건 | Pass/Fail 평가 과목. 학점 수가 없음 |
| `0` | `grade` 25건, `credit` 45건 | **실제 0** (예: 학년 무관, 0학점 필수 과목). 결측으로 바꾸지 마십시오 |

`description`(교과목 개요)의 결측은 **원 자료에서 교과목 개요를 찾지 못한 경우**입니다. 억지로 채우지 않았습니다.

### 3.4 다중값

한 칸에 값이 여럿인 열이 있습니다. **JSON에서는 배열**, CSV에서는 세미콜론 연결입니다.

```
CSV   detailedField = 중국문화학;중국현대문학
JSON  "detailedField": ["중국문화학", "중국현대문학"]
```

대상 열: `wideField`, `detailedField`, `categoryA`, `categoryB`, `referenceURL`, `descriptionSourceURL`

> **주의 — 구분자가 통일되어 있지 않습니다.** 위 열은 세미콜론이지만, `department`·`major`·`track`의 `sort` 열에는 쉼표로 연결된 값(`어문학, 중국학`, 5건)이 있고, `course`의 `sortD`에는 슬래시(`기초/진로`, 1건)가 있습니다. 이들은 배열로 변환하지 않고 **문자열 그대로** 두었습니다. 원본 표기를 보존하기 위한 결정입니다. `detailedField`의 `음성/음운론` 같은 슬래시는 전공명 자체에 든 것으로 구분자가 아닙니다.

### 3.5 숫자 열

CSV에서는 모든 값이 문자열입니다. JSON에서는 다음 열을 숫자로 변환했습니다.

| 자료형 | 열 |
|---|---|
| 정수 | `no`, `aYear`, `eYear`, `oYear`, `curriumYear`, `grade`, `semester` |
| 숫자(정수 또는 실수) | `credit` — `0.25`·`0.5` 학점이 있어 실수를 허용 |
| 실수 | `latitude`, `longitude` |

숫자로 바꿀 수 없는 값(`3~4`, `계절`, `P`, `-`)은 JSON에서도 **문자열로 남습니다.** 4.6의 주의를 보십시오.

## 5. 알려진 한계

1. **단년도 자료입니다.** 2025년 교육과정만 담고 있어 시계열 분석이 불가능합니다. `previousDescription` 16건만 이전 교육과정의 흔적입니다.
2. **교과목이 붙는 단위가 대학마다 다릅니다.** 학과만 세면 3개 대학이 0으로 잡힙니다(1절 참조).
3. **`grade`·`semester`·`credit`의 자료형이 섞여 있습니다.** (4.6 참조)
4. **`sortA`·`sortD`·`categoryB`는 결측률이 84~94%입니다.** `sortA`는 결측이 "교직 과목 아님"을 뜻하지만, `sortD`·`categoryB`는 미입력인지 해당 없음인지 구분되지 않습니다. 이 열로 집계할 때는 분모를 명확히 하십시오.
5. **`description`은 27.7%가 결측입니다.** 원 자료에서 교과목 개요를 찾지 못한 경우입니다. 개요가 있는 교과목만으로 텍스트 분석을 하면 표본이 편향될 수 있습니다.
6. **분류(`categoryA`, `categoryB`, `sort`, `wideField`, `detailedField`)는 연구팀의 판단입니다.** 대학이 공시한 분류가 아니라 수집 과정에서 부여한 것으로, 분류 기준의 신뢰도 검증 절차는 문서화되어 있지 않습니다.
7. **`content`(교육목표)와 `description`(교과목 개요)은 제3자 저작물입니다.** (4.5 참조, [`provenance.md`](provenance.md))
8. **교원 성명은 복원할 수 없습니다.** 익명화는 되돌릴 수 없는 처리입니다.
9. **URL의 유효성은 보장하지 않습니다.** 수집 시점의 주소이며, 대학 홈페이지 개편으로 끊길 수 있습니다. 일부 URL(13건)에는 세션 식별자(`jsessionid`)가 포함되어 있으나 링크 동작을 위해 그대로 두었습니다.

## 6. 재현

`data/raw/`의 원본에서 모든 산출물을 다시 만들 수 있습니다.

원본은 수정하지 않습니다. 정정이 필요하면 원본을 고친 뒤 스크립트를 다시 실행하고, 변경 내용을 [`CHANGELOG.md`](../CHANGELOG.md)에 기록합니다.

| URL의 `_ga`·`_gid` 추적 파라미터 제거 | URL 열 | 수집자 브라우저의 추적 ID. 자료와 무관 |
